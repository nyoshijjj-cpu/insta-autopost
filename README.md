# インスタ自動投稿

`posts/queue` に入れた写真を、**月・水・金の20時(日本時間)** に1枚ずつ自動でインスタに投稿します。

## 投稿の予約のしかた(スマホでもOK)

1. GitHub でこのリポジトリを開く
2. `posts/queue` フォルダを開いて「Add file → Upload files」
3. 写真と、同じ名前のキャプション用テキストをアップロード
   - 例:`001_cake.jpg` と `001_cake.txt`(中身がキャプション。ハッシュタグもここに書く)
   - **ファイル名の順番に投稿されます**(001, 002, 003…と番号をつけると分かりやすい)
   - キャプションがなければ写真だけ投稿されます
4. 「Commit changes」を押して完了

投稿されたものは `posts/posted` に移動し、`posts/posted/log.csv` に記録されます。

### 写真について
- iPhone の写真(HEIC)、PNG もそのまま入れてOK。自動でインスタ用のJPEGに変換します
- インスタに載せられる比率(縦長は4:5、横長は1.91:1)を超える写真は、**中央を自動で切り抜き**ます

## 手動で動かす・テストする
「Actions」タブ →「Instagram 自動投稿」→「Run workflow」
- 「テストだけ」にチェックあり:投稿せずに、次に投稿される内容と接続を確認
- チェックなし:今すぐ1件投稿

## 曜日・時間を変える
`.github/workflows/post.yml` の `cron` の行を変更します(時刻はUTC=日本時間−9時間)。
- 毎日20時:`"0 11 * * *"`
- 火・木・土の19時:`"0 10 * * 2,4,6"`

## 注意
- このリポジトリは**公開**です(インスタに画像を渡すため)。予約中の写真は、URLを知っている人なら投稿前に見られます
- トークンは GitHub の Secrets に保存しています。コードやファイルに直接書かないでください
- 失敗すると GitHub から登録メールに通知が届きます
- 投稿上限は24時間で100件です(このしくみでは1日最大1件)
